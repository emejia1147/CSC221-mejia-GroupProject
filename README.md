# Group Project for CSC 221 2026FA

**Owner:** Eric Mejia - [emejia1@my.waketech.edu](mailto:emejia1@my.waketech.edu)

**Project Description:** A Python data collection program inspired by NASA's Lucy mission that uses the NASA/JPL Small-Body Database REST API to collect and analyze orbital and physical properties of Jupiter's Trojan asteroids.

**URL for Data Collection:** [NASA/JPL Small-Body Database Query API](https://ssd-api.jpl.nasa.gov/sbdb_query.api?fields=full_name,a,e,i,H,q,ad,per&sb-class=TJN&limit=100)

**Collaborator:** Marg McIntire - [mvmcintire@my.waketech.edu](mailto:mvmcintire@my.waketech.edu)

# IMPORTANT INFO:

No API key is required for this program. The program uses the Python Requests and Pandas libraries to retrieve and organize data on Jupiter's Trojan asteroids.
